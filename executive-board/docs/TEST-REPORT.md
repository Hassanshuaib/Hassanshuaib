# Acceptance Test Report — 2026-11-23

**Environment:** Claude Code 2.1.330 (headless, `claude -p`), Linux cloud container. The plugin was installed from the local marketplace (`claude plugin marketplace add <repo>` and `claude plugin install executive-board@hassan-board`). `claude plugin validate` passed for both the marketplace and the plugin; the only warning is a missing icon.

**Method:** real sessions, run with `tests/run.sh`. `tests/summ.py` extracts every tool call from the stream-json output, which shows which agents were actually invoked. All business data is **fictional**: "Najm Cafe", a specialty-coffee office-subscription idea in Riyadh, and a fitness app.

**Evidence:** the per-test tool-call logs and final answers are in `tests/transcripts/*.txt`. Generated artifacts are in `tests/sample-output/`.

## Known limitations

- **Automatic delegation** in a plain session depends on the model matching agent descriptions. It worked in F2 but is not guaranteed. Explicit phrasing or `--agent` is reliable.
- **Independence:** executives are one model with different instructions. This is stated in every verdict.
- **PDF punctuation:** mixed Arabic and English lines occasionally misplace a trailing full stop or bracket. This is a LibreOffice bidi limitation. Saving the DOCX as PDF from Word avoids it.
- **The test environment is ephemeral:** the container's `~/.claude` install disappears. Your durable copy is the plugin in this repository.
