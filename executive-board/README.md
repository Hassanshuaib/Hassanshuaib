# مجلسك التنفيذي الذكي (AI Executive Board)

نظام جاهز داخل **Claude Code**: أنت الرئيس التنفيذي (CEO)، و**رئيس الديوان (Chief of Staff)** هو من تتكلم معه. يناقشك ويتحداك، ويستدعي المختص المناسب عند الحاجة فقط، ويحفظ قرارات كل مشروع في ملفاته الخاصة، ويجهّز تقارير Word و PDF و Excel.

تكلم بالعربي أو الإنجليزي. لا تحتاج تكتب أي كود.

---

## أعضاء المجلس

| العضو | دوره |
|---|---|
| **رئيس الديوان** (Chief of Staff) | واجهتك الوحيدة. يدير النقاش، ويوزع المهام، ويلخص لك، ويتتبع الافتراضات والقرارات |
| **المدير المالي** (CFO) | NPV وIRR وDCF والميزانيات و unit economics ونقطة التعادل. حساباته تُنفَّذ ببرنامج ويمكن مراجعتها |
| **مدير العمليات** (COO) | الجدوى التشغيلية والطاقة والتوظيف وسلاسل الإمداد وKPIs |
| **مدير التسويق** (CMO) | الشرائح والتسعير و CAC/LTV والتموضع والتجارب السريعة |
| **مدير الاستراتيجية** (CSO) | دخول الأسواق ونموذج العمل و TAM/SAM/SOM والخيارات الاستراتيجية |
| **مدير المخاطر / محامي الشيطان** (CRO) | يتحدى الافتراضات ويحلل احتمالات الفشل مسبقاً (pre-mortem). يميّز الخطر الحرج من الخطر الذي يكفي أن نراقبه |
| **السكرتير التنفيذي** | المحاضر وسجل القرارات وقائمة المهام، والتقارير بصيغ DOCX/PDF/XLSX |

**تنبيه صريح:** كل الأعضاء نفس نموذج الذكاء الاصطناعي، لكن كل واحد بتعليمات وزاوية نظر مختلفة. هم ليسوا نماذج مستقلة.

---

## التثبيت (مرة واحدة على جهازك)

افتح Claude Code في أي مجلد، واكتب الأمرين التاليين بالترتيب:

```
/plugin marketplace add hassanshuaib/hassanshuaib
/plugin install executive-board@hassan-board
```

- **إذا لم يُدمج الفرع بعد في الفرع الرئيسي:** اكتب في الأمر الأول بدلاً منه:
  `/plugin marketplace add hassanshuaib/hassanshuaib#claude/ai-executive-board-system-61jmqc`
- **إذا كان المستودع خاصاً (private):** جهازك يحتاج صلاحية دخول GitHub عبر git. التفاصيل في `docs/TECHNICAL.md`.
- **للتحقق:** اكتب `/agents`، ويجب أن ترى أسماء مثل `executive-board:cfo`.

**بديل يدوي بدون plugins:** شغّل `executive-board/install-manual.sh`. إذا كان عندك ملف بنفس الاسم سيأخذ منه نسخة احتياطية أولاً.

## الاستخدام اليومي

1. أنشئ مجلداً لكل مشروع أو شركة، مثلاً `Projects/مقهى-نجم`، وافتح Claude Code فيه.
2. ابدأ بإحدى ثلاث طرق، كلها تعمل:
   - **الأفضل:** `claude --agent executive-board:chief-of-staff`
   - **أو** اكتب `/executive-board:board` داخل أي محادثة.
   - **أو** ابدأ الكلام مباشرة عن مشروعك. غالباً يتعرف Claude على الطلب ويستدعي المجلس تلقائياً، لكن هذا ليس مضموناً 100%.
3. **اجعله يفتح تلقائياً:** في أول مرة سيسألك رئيس الديوان إن كنت تريد إنشاء مجلد `board/` للمشروع. وافق، واطلب منه: "خلّك الافتراضي في هذا المجلد". بعدها يكفي أن تكتب `claude` فقط.

### أمثلة لما تقوله

| تقول | ما يحدث |
|---|---|
| "عندي فكرة مشروع جديد، خلنا نعصف ذهنياً" | نقاش مع رئيس الديوان فقط، بلا تكلفة إضافية |
| "اسأل المدير المالي يقيّم استثمار 300 ألف ريال" | يحلل المدير المالي، ويحدد البيانات الناقصة، ويكتب الافتراضات والسيناريوهات |
| "أرسل افتراضات المدير المالي لمدير العمليات" | مدير العمليات يقرأ ملف التحليل نفسه، ويقبل كل افتراض أو يعدّله أو يرفضه |
| "اجمع المجلس وتحدّوا القرار" | مجلس **Lite**: 2–3 مختصين ومدير المخاطر يحللون بالتوازي، ثم يصدر حكم واضح فيه نقاط الخلاف |
| "أبي مراجعة معمقة / peer review" | مجلس **Standard**: يضيف جولة مراجعة متبادلة بأسماء مخفية. تكلفته أعلى |
| "خلّ السكرتير يجهز تقرير Word و PDF و Excel" | تُنشأ الملفات فعلاً في `board/reports/`، ويُعطيك مكانها |
| "كمّل نقاشنا السابق" | يقرأ ملفات `board/` ويلخص لك أين وصلتم |

## ذاكرة القرارات: مجلد `board/` داخل كل مشروع

يحتوي على:
- `context.md`: ملخص المشروع
- `assumptions.md`: سجل الافتراضات
- `decisions/`: قرار مستقل لكل موضوع (DEC-001 وما بعده)، وسجل يجمعها
- `minutes/`: المحاضر
- `analyses/`: تحليلات الأعضاء الكاملة، والسكربتات التي حسبوا بها
- `actions.md`: المهام، ولكل مهمة مسؤول وموعد
- `reports/`: التقارير
- `lessons.md`: الدروس المستفادة

**الخصوصية:**
- كل مشروع معزول عن غيره. لا يقرأ المجلس مجلد مشروع آخر إلا بإذنك الصريح.
- لا تُحفظ بيانات أي شركة في الإعدادات العامة.
- لا يحفظ أبداً كلمات المرور أو المفاتيح أو بيانات البنوك.
- إذا كان المشروع داخل git، يمكن إضافة `board/` إلى `.gitignore` حتى لا يُرفع بالخطأ.

**القرار لا يصبح "معتمداً" إلا بكلمتك.** قبل ذلك تبقى حالته "مقترح".

## التكلفة والاستهلاك

القيم التالية من اختبارات فعلية، محسوبة بسعر الـ API القياسي على نموذج Opus. في الاشتراكات (Pro/Max) تُخصم من حدود الاستخدام بدل الفاتورة.

| النشاط | عدد الوكلاء | التكلفة التقريبية |
|---|---|---|
| نقاش أو عصف ذهني | 0 | 0.2 – 0.5$ |
| سؤال لمختص واحد | 1 | ≈ 0.3 – 1.1$ |
| مجلس Lite | 3–4 | ≈ 1.7$ |
| مجلس Standard | 7 | ≈ 5$ |
| تقرير بثلاث صيغ | 1 | ≈ 1 – 2$ |

**القاعدة:** ابدأ دائماً بالنقاش، واستدعِ المختص عند الحاجة، واحتفظ بالمجلس الكامل للقرارات الكبيرة.

## الأمان

- **كل شيء محلي.** المجلس لا يتصل بأنظمة محاسبة أو بنوك، ولا يرسل رسائل، ولا ينفذ أي عملية مالية، إلا بموافقتك الصريحة في كل مرة.
- البحث العام على الإنترنت مسموح للقراءة فقط، والمصادر تُذكر.
- هذه التحليلات ليست استشارة مرخّصة. راجع مختصاً في الأمور القانونية والضريبية والزكاة.

## الصيانة والإزالة

| المطلوب | الطريقة |
|---|---|
| تحديث | `/plugin marketplace update hassan-board` |
| تعطيل مؤقت | `/plugin` ثم اختر الإضافة وعطّلها |
| إزالة كاملة | `/plugin uninstall executive-board@hassan-board` |

- مجلدات `board/` في مشاريعك **لا تُحذف أبداً** عند الإزالة.
- إذا ثبّتّ النسخة اليدوية: أزلها بـ `uninstall-manual.sh`، وهو يعيد ملفاتك الأصلية.
- لإضافة عضو جديد للمجلس، مثل مدير قانوني أو مدير موارد بشرية، راجع `docs/TECHNICAL.md`.

## الترقية إلى مستوى الخبراء (الإصدار 1.1)

- **محرك حسابات مُتحقَّق منه** في `scripts/boardcalc.py`. يغطي المالية والعمليات والتسويق والاستراتيجية والمخاطر. تحققنا منه بـ 36 اختباراً قارناها بنتائج مستقلة، منها دوال LibreOffice نفسها ونموذج Excel بمعادلات حيّة. الأعضاء يحسبون بالكود، لا من الذاكرة.
- **لكل عضو حقيبة أدوات خاصة به** (toolkit)، تُحمَّل له تلقائياً. فيها طرق العمل ومعايير الجودة، وملفات مرجعية يقرأ منها فقط ما يحتاجه.
- **حزمة مالية اختيارية** (`board-finance-pack`): 7 مهارات رسمية من Anthropic، أضفناها بموافقتك كما هي دون تعديل. وهي: تدقيق نماذج Excel، والقوائم الثلاث، و LBO، ونموذج الاندماج، وعوائد الملكية الخاصة، والفحص النافي للجهالة، والتحليل التنافسي.
  - لتثبيتها: `/plugin install board-finance-pack@hassan-board`
- **رئيس الديوان صار يحوّل الأسئلة تلقائياً:**
  - السؤال البسيط يجيب عليه بنفسه.
  - النموذج أو التقييم أو القرار المهم يحوّله للمدير المالي.
  - القرار الكبير (≥ 250 ألف ريال أو صعب التراجع عنه) يحصل تلقائياً على **مراجعة مستقلة من مدير المخاطر**.
- **نتائج الاختبار الحقيقية:** في `docs/EXPERT-TEST-REPORT.md`.
- **قائمة المهارات:** المثبّت منها والمصنوع والناقص في `docs/SKILLS-INVENTORY.md`.

**تنبيه صادق:** هذه التعليمات وحدها لا تجعل الأعضاء خبراء موثوقين. ما يرفع الموثوقية هو التحقق: الحساب بالكود، وفحوص سلامة النموذج، والمراجعة المستقلة.
