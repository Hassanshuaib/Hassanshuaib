# Board memory — {{PROJECT}}

This folder is the executive board's memory for **this project only**. It is plain Markdown, so you can read and edit it yourself.
Keep it private. If this folder sits in a git repository, `board/` should normally be listed in `.gitignore`.

| File / folder | Purpose |
|---|---|
| `context.md` | What the project is, its goals, constraints and key numbers |
| `brainstorm/` | Notes from idea sessions |
| `assumptions.md` | Assumptions register (ID, value, basis, status) |
| `decisions/register.md` | Index of all decisions |
| `decisions/DEC-NNN-*.md` | One record per significant decision (see `TEMPLATE.md`) |
| `minutes/` | Board meeting minutes and council verdicts |
| `analyses/` | Full analyses saved by each executive |
| `actions.md` | Action items: owner, due date or trigger, status |
| `reports/` | Executive reports (MD, DOCX, PDF, XLSX) |
| `lessons.md` | Lessons learned |
